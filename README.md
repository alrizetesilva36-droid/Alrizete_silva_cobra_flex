# Sistema Cobra Flex
# 🚗 FlexCalc Py - Calculadora de Combustível Atualizada (Norma E32)

O **FlexCalc Py** é um aplicativo desenvolvido em **Python** para ajudar motoristas a tomarem a melhor decisão financeira no posto de combustível. Ele foi totalmente projetado e calibrado para refletir as novas diretrizes da **Lei do Combustível do Futuro (Lei 14.993/24)**.

Com o aumento da mistura obrigatória de etanol anidro na gasolina para **32% (padrão E32)**, a eficiência da gasolina caiu ligeiramente, enquanto os motores Flex modernos se tornaram mais eficientes rodando com etanol puro. Por isso, a antiga "regra dos 70%" foi substituída pela **nova paridade de 75% (0.75)** recomendada por engenheiros automotivos.

---

## 📌 Como funciona a Nova Regra de Cálculo?

O script realiza o cálculo utilizando a nova linha de corte de **75%**.

\[\text{Relação} = \frac{\text{Preço do Etanol}}{\text{Preço da Gasolina}}\]

* **Resultado < 0.75:** O aplicativo recomenda **Etanol** 🌿 *(Mais vantajoso)*
* **Resultado ≥ 0.75:** O aplicativo recomenda **Gasolina** ⛽ *(Mais vantajoso)*


## 🚀 Funcionalidades

* 📊 **Algoritmo E32:** Calibrado para a nova realidade dos combustíveis no Brasil.
* 🐍 **Interface Python Pura:** Executável via terminal ou interface gráfica simples.
* 💰 **Projeção de Economia:** Mostra o valor poupado com base na capacidade total do tanque.
